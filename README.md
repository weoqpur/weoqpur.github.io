# 신무결의 AI 노트

[블로그 보기](https://weoqpur.github.io/) · [이력서](https://profile.radish-mu.cloud/)

GitHub Pages와 Jekyll로 운영하는 기술 블로그입니다. `main`에 푸시하면 자동 배포됩니다.

## 새 글 작성

`_posts/YYYY-MM-DD-slug.md` 파일을 만들고 다음 형식으로 작성합니다.

```markdown
---
layout: post
title: "글 제목"
description: "글을 소개하는 한 문장"
date: 2026-10-07 12:00:00 +0900
category: 회고
tags: [AI, 실험]
---

본문을 Markdown으로 작성합니다.
```

배포하지 않을 글은 `_drafts/`에 저장합니다. 날짜와 제목을 지정해 `_posts/`로 옮기면 공개됩니다.

## 로컬 실행

Ruby와 Bundler가 설치된 환경에서 `bundle install`, `bundle exec jekyll serve`를 실행합니다.
